# 税后收入计算器

中国大陆 GDP 前 30 城市工资薪金税后收入计算器。

## 功能

- 月工资 + 年终奖。
- 全年一次性奖金单独计税 / 并入综合所得 / 自动择优。
- 城市五险一金当前政策快照。
- 社保/公积金缴费基数上下限及实际扣除额。
- 公积金默认比例 / 自定义个人和公司比例。
- 专项附加扣除。
- 每月税后收入及年度汇总。
- Offer / 调薪方案对比。
- 纯前端计算，不上传精确收入数据。
